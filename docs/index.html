Feature Search

Enter comma-separated Feature IDs to pull full details from Azure DevOps — sortable, selectable, and linkable.

Child User Stories

Fetch child stories with board column, deploy/target dates, tags, and parent feature links — with date highlighting for past-due items.

🧪

Test Case Review

Search test cases by iteration with filtering on status, assignee, automation, priority, and complexity.

👥

QA Assignments

Find stories assigned to QA or in "In Progress(QA)" with expandable bug trees and visual status charts.

✨ AI-Powered

Summaries that stick

Click "Generate AI Summary" above any chart or table. Powered by NVIDIA NIM, each summary is rendered with markdown formatting and saved to localStorage — so it survives page refreshes and filter changes. Regenerate anytime to refresh with current data.

  • ✓ On-demand generation per tab
  • ✓ localStorage persistence
  • ✓ Markdown-formatted output
  • ✓ Collapsible, dismissible UI
